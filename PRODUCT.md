# Scoundrel

## Platform
Web. Personal single-player browser fantasy card game.

## Product purpose
Play the original Scoundrel solitaire dungeon game using a 44-card deck. The React interface presents a pure TypeScript engine, with original rules credited to Zach Gage and Kurt Bieg. Rule interpretations live in README.md.

## Confirmed constraints
Vite, React and TypeScript; no runtime backend. Accessible keyboard controls and small-screen support. Preserve the illustrated bronze card frames, parchment nameplates and top-aligned monster art. Actions sit outside card faces. Remove unnecessary subtitles and card type badges. Treat the surrounding interface as a fantasy card game, not an informational website. Use generated art for illustrated surroundings.

## Open decisions
Deployment and saved-game behaviour.
